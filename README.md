# CHAPOLO EXTREMO V23 · PLATAFORMA

Centro de Comando Deportivo offline-first para organizar un análisis de fútbol de principio a fin.

## Flujo
PARTIDO → CONTEXTO → TÁCTICA → JUGADORES/H2H → PERRO CHAPOLO → ANTIFALLO → MERCADOS → AUDITORÍA → VEREDICTO → HISTORIAL

## Incluye
- Logo e identidad CHAPOLO EXTREMO.
- Centro de Comando / Comandante Chapolo.
- Persistencia local de hasta 50 análisis.
- xG, PPDA, xThreat, córners, tiros, tiros a puerta y tarjetas.
- Perfil de goles globales y por mitad.
- Faltas, jugadores, minutos, lesiones/sanciones, árbitro, clima/cancha, entrenadores y H2H.
- Perro Chapolo heurístico.
- Antifallo con controles explícitos.
- Mercados seleccionables y auditoría.
- Veredicto final condicionado a evidencia suficiente.
- PWA: manifest, logo e instalación/service worker cuando se sirva por HTTPS.

## Importante
La aplicación no inventa datos ni sustituye una fuente deportiva externa. Los campos deportivos se introducen manualmente o se integran después con una fuente/API verificada.
